# Safety

- Lithium cells: test before use, matched cells per pack, a BMS and a fuse on every pack, cases that
  survive a fall, no charging unattended until the dock has been tested.
- A robot a dog can knock over must not be able to short a pack when it falls: recessed terminals,
  keyed connectors, fused outputs.
- AC only in its own module with its own connector, never on the shared bus.
- Pets: no pinch points that a nose or paw can reach; soft cover.
