# Open questions

- Bus: CAN or I2C? (CAN tolerates hot-plug and long runs; I2C is simpler.)
- Connector: which magnetic pogo connector, how many pins, what current rating?
- Pack: 4S? How many in parallel? What runtime is enough?
- Size: how tall, how heavy, how wide a base?
- Look: what friendly non-human shape?
- How does it get between floors, if at all?
- License for the designs, so others can build attachments.
